# tabumenu.fyt.life

The QR table menu for Tabu Shabu, Orange (111 S Glassell St, Orange, CA 92866), served by GitHub Pages from `main` at the repo root.

The menu is built in the private brand repo (`kei-brand-menus`, brand folder `tabu-shabu`) and copied here to publish; edit the source there, never the built files here. `CNAME` is added only once the `tabumenu` DNS record resolves.
