Printed QR codes

Every code below opens the address on its line, which then forwards to the menu. Print only these addresses; a menu page's own path never goes on paper, so a page can move without a reprint.

  • Print each code at least 30 mm wide, with the white margin the PNG already carries (four modules) left untouched; never below 25 mm.
  • The PNGs are 2048 px with error-correction level H, so the restaurant's mark in the centre is tolerated; do not add anything else on top of the code.
  • Before a print run, scan the proof with two different phones and confirm the menu opens.
  • Printing this page gives one card per sheet with the code at 60 mm.
